## الحالات

| الحالة | تعني | الزر التالي |
| --- | --- | --- |
| جديد | وصل ولم يُتواصل معه | تم التواصل |
| تم التواصل | تحدث المندوب مع العميل | أُرسل عرض |
| أُرسل عرض | عرض السعر خرج من خارج البوت | تم البيع |
| تم البيع | انتهى | إعادة فتح |
| لم يكتمل | انتهى بسبب: السعر، لا مخزون، منافس، لم يرد، تأجيل المشروع، غير ذلك | إعادة فتح |

أسباب عدم الاكتمال مقترحة، وتُعدَّل في `data/options.json` بعد اعتماد مدير المبيعات.

## الإسناد

الإسناد الافتراضي للأقل حملاً بين مندوبي الفرع النشطين. إن لم يوجد مندوب للفرع يصل الطلب للمدير مع زر إسناد. يمكن جعله يدوياً بـ `ASSIGN_MODE=manual`.

## المخزون

ملف Excel يحوي عموداً للكود أو الاسم وعموداً للكمية، ويُفضَّل عمود للموقع بصيغة `1000-FGD`. المواقع القابلة للبيع: منتج تام (FGD) وألواح (SLB) وصالة العرض (SHW). يُستبعد: البلوكات والسكراب والمحاجر والتحت التشغيل. كود أودو القديم يتحول تلقائياً للكود والاسم المعياريين (1,429 صنفاً من ملف الأصناف النظيفة). أي عمود تكلفة أو سعر يُهمل ولا يُخزَّن.

البحث يفهم: الخامة، الاسم التجاري بالعربي والإنجليزي، المقاس، السمك، التشطيب، والمنتج. أمثلة:

| ما يُكتب | ما يُفهم |
| --- | --- |
| بيانكو 60×30 2 سم لامع | Bianco بلاط 60×30 سمك 2 لامع |
| عندنا ايه جرانيت 3 سم | كل الجرانيت بسمك 3 |
| الرخام لوح | ألواح الرخام |
| رويال جولد | Royal Gold |

إن لم توجد نتيجة بكل الشروط يخفف البوت السمك ثم المقاس ثم التشطيب ويقول ذلك. تهجئات الأسماء بالعربي في `data/aliases.json` وتُضاف بلا كود.

## الراكد

يُحدَّد من عمود راكد في ملف المخزون، أو بإرسال ملف اسمه يحوي كلمة راكد فيه أكواد الأصناف. يظهر بعلامة، ويأتي أولاً في البدائل. تخفيض الراكد لا يُعرض برقم: القرار لمدير المبيعات عبر طلب الاعتماد، إلى حين اعتماد سياسة الخصم.

## الاعتمادات

حدود الاعتماد التلقائي في `data/policy.json` وهي فارغة الآن، فكل الطلبات تذهب للمدير. عند اعتماد المدير العام لحد الخصم أو الائتمان يُكتب الرقم هناك فيعتمد البوت ما دونه تلقائياً ويسجله.

## أودو (قراءة فقط)

| الميزة | تعتمد على |
| --- | --- |
| ملف العميل: آخر الأوامر والمتأخرات | بحث بالجوال أو الاسم في العملاء |
| التحصيل: المتأخر لعملائك، اتصلت، وعد بالسداد | فواتير العملاء المنشورة المتأخرة |
| المبيعات: الشهر قبل الضريبة | فواتير العملاء والمرتجعات |
| مخزون حي (تجريبي) | `STOCK_SOURCE=odoo` ومواقع أودو الحالية، وهي ما زالت قبل إعادة الهيكلة |

المندوب يُربط بمستخدم أودو عند إضافته (`أودو:12`). بلا ربط لا يرى بيانات أودو.
